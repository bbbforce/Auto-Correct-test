【代码指南】
- 输出必须是一个完全可执行的 Python 脚本（.py），不要包含 markdown 或解释。
- 对于线性问题（如热传导、线弹性）：
  - 必须定义 `a`（使用 `TrialFunction` 的双线性形式）和 `L`（使用 `TestFunction` 的线性形式）。
  - 使用 `solve(a == L, u, bcs)`。不要使用 `F == 0`。
- 对于非线性问题（如超弹性、相场）：
  - 必须定义 `F`（使用 `Function`，不是 `TrialFunction` 的线性形式）和 `J = derivative(F, u, du)`。
  - 使用 `solve(F == 0, u, bcs, J=J, solver_parameters={"newton_solver": {"linear_solver": "mumps"}})`。
- 文件保存关键规则（必须使用 result_dir 变量，不得硬编码路径）：
  - 脚本顶部必须定义：`result_dir = os.environ.get("RESULT_DIR", "result")`，然后 `os.makedirs(result_dir, exist_ok=True)`。
  - 所有文件/图片保存路径必须使用 `os.path.join(result_dir, "filename.ext")`，不得出现任何硬编码的目录字符串（如 `"result/"` 或 `"./output/"`）。

  - 如果使用 `File()`，只能用于 `.pvd` 文件，例如 `File(os.path.join(result_dir, "name.pvd"))`。
- 对于分母使用 `+ eps` 以提高数值稳定性（例如 `epsilon + eps`）。

【XDMF 数据导出规则（供 ParaView 后处理渲染使用）】
- 仿真完成后，必须使用 `XDMFFile` 将关键物理量保存为 XDMF+H5 文件对。这些数据会被 ParaView 自动读取和渲染，产出高质量可视化图片。
- 典型保存示例：

- 对于 gmsh 生成的临时网格文件（`.msh`），可以在转换为 FEniCS Mesh 后清理，但最终提交到 `result_dir` 的 XDMF+H5 结果文件必须保留。
